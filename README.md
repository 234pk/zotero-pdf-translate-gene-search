# Zotero PDF Translate & UniProt Search 插件

[![zotero target version](https://img.shields.io/badge/Zotero-7/8-green?style=flat-square&logo=zotero&logoColor=CC2936)](https://www.zotero.org)
[![Latest Release](https://img.shields.io/badge/Release-v2.4.4-blue?style=flat-square)](https://github.com/234pk/zotero-pdf-translate-gene-search/releases/latest)

## 中文介绍

**Zotero PDF Translate & UniProt Search** 是一个功能强大的 Zotero 插件，专为学术研究设计，集成了翻译功能和蛋白质数据库搜索功能。

### 主要功能特色

#### 🔤 智能翻译功能
- **PDF/EPub/网页翻译**：在 Zotero 阅读器中直接翻译选中的文本内容
- **多服务支持**：集成 20+ 翻译服务（Google Translate、DeepL、Microsoft、百度翻译等）
- **自动翻译**：支持注释、元数据、标题和摘要的自动翻译
- **词典功能**：单词级翻译和发音功能
- **句子逐句翻译**：支持按句子进行精细翻译

#### 🔬 UniProt 蛋白质搜索
- **物种分类搜索**：支持按不同物种分类搜索蛋白质信息
- **智能缓存管理**：优化的搜索结果缓存机制，确保物种切换时正确更新
- **实时搜索**：集成 UniProt 数据库，提供专业的蛋白质信息查询

#### 🎯 技术优势
- **智能缓存系统**：先进的缓存管理，避免重复搜索
- **任务队列优化**：高效的任务执行和结果处理
- **多语言界面**：完整的中英文界面支持
- **Zotero 7/8 兼容**：完美支持最新版本的 Zotero

### 安装和使用
1. 下载最新的 `.xpi` 文件
2. 在 Zotero 中安装插件
3. 在设置中配置翻译服务参数
4. 在阅读器中选中文本即可使用翻译功能
5. 使用 UniProt 搜索功能查询蛋白质信息

## English Introduction

**Zotero PDF Translate & UniProt Search** is a powerful Zotero plugin designed for academic research, integrating translation capabilities with protein database search functionality.

### Key Features

#### 🔤 Smart Translation
- **PDF/EPub/Webpage Translation**: Direct translation of selected text within Zotero reader
- **Multi-Service Support**: Integration with 20+ translation services (Google Translate, DeepL, Microsoft, Baidu, etc.)
- **Automatic Translation**: Support for annotations, metadata, titles, and abstracts
- **Dictionary Function**: Word-level translation and pronunciation features
- **Sentence-by-Sentence Translation**: Fine-grained translation at sentence level

#### 🔬 UniProt Protein Search
- **Species-Specific Search**: Search protein information by different species classifications
- **Smart Cache Management**: Optimized search result caching for proper updates during species switching
- **Real-time Search**: Integrated UniProt database for professional protein information queries

#### 🎯 Technical Advantages
- **Intelligent Caching System**: Advanced cache management to avoid duplicate searches
- **Task Queue Optimization**: Efficient task execution and result processing
- **Multi-language Interface**: Full Chinese and English interface support
- **Zotero 7/8 Compatible**: Perfect support for the latest Zotero versions

### Installation and Usage
1. Download the latest `.xpi` file
2. Install the plugin in Zotero
3. Configure translation service parameters in settings
4. Select text in reader to use translation features
5. Use UniProt search function for protein information queries
