# Zotero PDF Translate 插件介绍 / Zotero PDF Translate Plugin Introduction

## 中文介绍

**Zotero PDF Translate** 是一个功能强大的 Zotero 插件，专门用于学术文献的翻译和语言处理。

### 主要功能
- **PDF/EPub/网页翻译**：支持在 Zotero 阅读器中直接翻译选中的文本内容
- **多服务支持**：集成 20+ 翻译服务，包括 Google Translate、DeepL、Microsoft Translate、百度翻译等
- **智能翻译**：支持自动翻译注释、元数据、标题和摘要
- **UniProt 搜索**：集成 UniProt 数据库，支持按物种分类搜索蛋白质信息
- **词典功能**：单词级翻译和发音功能
- **独立翻译窗口**：提供独立的翻译界面，支持多服务对比翻译
- **句子逐句翻译**：支持按句子进行精细翻译

### 技术特点
- 支持 Zotero 7/8 版本
- 基于现代化的插件模板开发
- 智能缓存和任务队列管理
- 多语言界面支持

## English Introduction

**Zotero PDF Translate** is a powerful Zotero plugin designed for academic literature translation and language processing.

### Key Features
- **PDF/EPub/Webpage Translation**: Direct translation of selected text within Zotero reader
- **Multi-Service Support**: Integration with 20+ translation services including Google Translate, DeepL, Microsoft Translate, Baidu Translate, etc.
- **Smart Translation**: Automatic translation of annotations, metadata, titles, and abstracts
- **UniProt Search**: Integrated UniProt database with species-specific protein information search
- **Dictionary Function**: Word-level translation and pronunciation features
- **Standalone Translation Window**: Independent translation interface with multi-service comparison
- **Sentence-by-Sentence Translation**: Fine-grained translation at sentence level

### Technical Features
- Compatible with Zotero 7/8
- Built on modern plugin template
- Intelligent caching and task queue management
- Multi-language interface support

## 安装和使用
- 下载最新的 .xpi 文件并安装到 Zotero
- 在 Zotero 设置中配置翻译服务参数
- 在阅读器中选中文本即可使用翻译功能

## Installation and Usage
- Download the latest .xpi file and install in Zotero
- Configure translation service parameters in Zotero settings
- Select text in reader to use translation features
